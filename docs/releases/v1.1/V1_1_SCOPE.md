# v1.1 setup scope

This is a development setup document, not a product roadmap or feature
commitment.

## Goals

- Mature and stabilize the v1.0 baseline.
- Prepare a careful transition from SangerFlow to Sanger Analysis Flow (SAF).
- Improve workflow usability without destabilizing the scientific core.
- Strengthen validation and traceability.

## Candidate improvements under evaluation

The following are candidates only. They require separate design, validation,
and scope approval before implementation.

- Conflict and low-quality navigation in Consensus Review.
- Better navigation from an evidence item back to its source.
- External alignment import with metadata-identity preservation.
- Improved regression validation and public/private test boundaries.
- Rename and branding migration planning for SAF.

## Explicitly not part of initial v1.1 setup

- Phylogenetic inference implementation.
- A BEAST replacement.
- Population-genetic analysis implementation.
- A large multi-locus concatenation system.
- A partition-management system.
- Major scientific algorithm replacement.
- Windows support claims without actual validation.
- BOLD online-integration claims.

Multi-locus, concatenation, and partition functionality may be considered in a
later version only after a dedicated design audit.
